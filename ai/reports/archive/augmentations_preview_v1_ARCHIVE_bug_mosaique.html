🔍 Vérification visuelle des augmentations

Comment lire cette page :

  • Cadre VERT = image originale (référence)
  • Cadre BLEU = image générée par augmentation

✅ Checklist qualité — Pour chaque image augmentée, vérifier :

  • La feuille est reconnaissable (pas de mosaïque/kaléidoscope)
  • Pas de motifs répétés en miroir
  • Les zones vides sont en noir (pas en motif reflété)
  • L'image reste botaniquement réaliste
  • La maladie (taches, décolorations) reste visible si présente

Si tu vois des problèmes :
1. Note les classes problématiques
2. Lance python augment_weak_classes_v2.py --rollback
3. Ajuste les paramètres dans le script et regénère
